Quick reminder: active to passive

The object (O) becomes the new subject. The verb becomes be + V3/ed. The old subject (S) moves to by + S.

Present simple
am/is/are + V3
Tom paints it. → It is painted by Tom.
Present continuous
am/is/are + being + V3
It is being painted by Tom.
Present perfect
has/have + been + V3
It has been painted by Tom.
Past simple
was/were + V3
It was painted by Tom.
Past continuous
was/were + being + V3
It was being painted by Tom.
Future simple
will + be + V3
It will be painted by Tom.
Be going to
am/is/are going to + be + V3
It is going to be painted by Tom.
Modal verbs
can / should / must / may / had better + be + V3
It can be painted by Tom.
Word order: place → by + S → time. Example: The tombstones were restored in the courtyard by the craftsmen last year.
